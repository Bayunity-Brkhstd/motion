Panduan & FAQ: Motion Standar (Short-Form 9:16)

Ubah topik sederhana atau naskah JSON menjadi video animasi vertikal 1080×1920 30fps siap posting di Shorts, Reels, dan TikTok.

Tutorial Langkah demi Langkah Menggunakan Motion

1

Tentukan Isi Konten

Pilih tab Dari topik (AI) dan ketik tema video 1 kalimat, atau gunakan tab Tempel naskah JSON dari Gemini Canvas untuk kontrol cerita yang presisi.

2

Pilih Template Gaya

Pilih dari 25+ template gaya visual yang tersedia di grid (termasuk template kustom hasil ekstraksi video Anda di posisi paling atas).

3

Atur Narasi & Audio

Pilih Suara Bawaan / AI (Windows SAPI atau VoxCPM2 lokal) atau klik Upload Audio Sendiri jika Anda sudah memiliki rekaman narator.

4

Klik Buat Video

Tekan tombol biru Buat video. Engine Remotion akan merender video secara deterministik menjadi file MP4 beresolusi 1080×1920 30fps.

Berapa durasi ideal video animasi di Motion standar?

Durasi ideal untuk Motion standar adalah antara 30 detik hingga 90 detik (3 sampai 8 adegan). Format ini paling optimal untuk konten berformat vertikal seperti YouTube Shorts, Instagram Reels, dan TikTok.

Jika Anda memerlukan video narasi panjang di atas 4 menit, silakan gunakan tab Motion Pro.

Apa keuntungan menggunakan tab "Tempel Naskah JSON"?

Dengan mode naskah JSON, Anda memiliki kendali penuh atas:

  • Teks judul dan kalimat narasi persis untuk tiap adegan.
  • Kata kunci ilustrasi visual yang ingin digambarkan oleh AI.
  • Durasi detik masing-masing adegan.

Anda dapat mengklik banner Aplikasi Canvas Gemini di Beranda untuk membuat struktur naskah JSON secara interaktif dan menyalinnya ke Motion.

Apakah AI menggambar objek tiap adegan membutuhkan kuota API?

Toggle AI menggambar objek tiap adegan menggunakan AI untuk menghasilkan ilustrasi SVG kustom menggantikan emoji standar. Jika Anda menggunakan mode Lokal atau akun gratis Google Gemini di Pengaturan AI, fitur ini gratis tanpa biaya API terpisah.

Bagaimana cara menambahkan logo dan font kustom sendiri?

Di halaman Motion pada panel kiri, terdapat tombol + Pilih Logo dan + Font Kustom. Anda dapat mengunggah file logo PNG/SVG dan file font TTF/WOFF2 yang akan otomatis diaplikasikan ke template render.

Bagaimana Studio Animasi Bergerak merender karakter dengan konsumsi RAM < 600 MB?

Studio Animasi Bergerak menggunakan arsitektur Plan B (Native Remotion Canvas 2D & Trigonometri Deterministik) yang berjalan langsung di engine React Remotion tanpa memerlukan browser headless Chromium/Playwright yang memakan RAM besar.

Semua sendi, langkah kaki, ayunan tangan, dan transisi kamera dihitung menggunakan rumus fisika pegas (closed-form springs) dan fungsi periodik sin/cos secara frame-by-frame, sehingga laptop spesifikasi standar (bahkan tanpa GPU diskrit) dapat merender video animasi vertikal 1080×1920 30fps dengan lancar.

Apa saja 3 rig karakter yang tersedia dan apa perbedaannya?
  • Toon 3D (Perspektif & Cel-Shaded): Karakter bergaya kartun modern dengan shading cel bergaris tegas, proporsi dinamis, dan kedalaman perspektif ala anime modern.
  • Stickman (Kinetik Jalan & Lari): Karakter figur garis minimalis dengan artikulasi sendi lincah, ideal untuk video humor, cerita fakta kilat, atau aksi cepat.
  • Isometric (3D Reka & Tech Grid): Karakter 3D berbasis kubus isometrik dengan bayangan proyeksi 30 derajat, sangat cocok untuk video edukasi, teknologi, atau infografis data.
Bagaimana sinkronisasi bibir (lip-sync) dan gerakan tubuh bekerja?

Gerakan dihitung otomatis berdasarkan durasi adegan dan frekuensi bicara voice-over. Mulut karakter terbuka dan menutup secara ritmis selaras dengan suku kata narasi, sementara mata berkedip secara natural setiap 3–4 detik dengan ekspresi alis dinamis sesuai nada kalimat (senang, terkejut, serius, atau bingung).

Apa fungsi tombol "Periksa Keyframe" sebelum render video?

Fitur Visual QA Keyframes mengambil snapshot pose kunci karakter di detik ke-2 tiap adegan hanya dalam 1 detik. Anda dapat memverifikasi kostum, pose tangan, dan latar belakang sebelum memutuskan untuk merender seluruh video MP4 secara penuh.

Mengapa Motion Pro diproteksi dengan kode akses?

Motion Pro adalah modul komputasi tingkat lanjut yang mengorkestrasi pipeline multi-layer (analisis audio jeda napas, rendering video durasi panjang berbabak-babak, dan reasoning AI agent). Kode akses digunakan untuk mengontrol stabilitas pemakaian dan memastikan akun CLI Anda telah siap digunakan.

Kenapa Motion Pro memakai CLI AI Langganan, bukan kunci API per-token?

Video panjang (4–15+ menit) membutuhkan ribuan token untuk menganalisis puluhan adegan, memetakan timing audio, dan menulis kode animasi Remotion. Jika menggunakan API per-token biasa, biaya tagihan akan sangat mahal.

Dengan memanfaatkan kuota langganan chat resmi Anda (seperti Gemini Advanced / Antigravity, Claude Pro/Max, atau ChatGPT Plus via CLI resmi), seluruh proses eksekusi memotong kuota langganan Anda yang sudah ada tanpa ada tagihan API terpisah!

Bagaimana format naskah Markdown (.md) yang benar untuk Motion Pro?

Naskah sebaiknya dibagi menjadi babak (heading # Babak) dan adegan (heading ## Adegan) dengan durasi 4 hingga 8 detik per adegan. Contoh:

# Babak 1: Pendahuluan
## Adegan 1: Hook
Pernahkah Anda bertanya-tanya mengapa konsistensi adalah kunci kesuksesan?

## Adegan 2: Masalah
Banyak orang menyerah di hari ke-14 karena kehilangan motivasi awal...
Bagaimana cara kerja sinkronisasi suara narasi (Voice-Over Alignment)?

AI memindai gelombang amplitudo file suara Anda untuk menemukan jeda hening / desah napas (silence gaps). Dari jeda tersebut, AI secara otomatis mencocokkan transkrip kalimat adegan dengan potongan waktu audio yang tepat (exact start & end timestamps).

Parameter visual apa saja yang diekstrak oleh AI dari video?

Skrip ekstraksi Python mengekstrak komponen penting:

  • Rasio Pacing & Ritme: Rata-rata durasi transisi perpindahan adegan.
  • 5 Palet Warna Dominan HEX: Palet warna background, aksen, dan teks.
  • Karakteristik Garis/Stroke SVG: Ketebalan border visual (tipis, tebal cel-shaded, atau flat).
  • Fisika Pegas (Spring Physics): Parameter damping, mass, dan stiffness untuk animasi Remotion yang natural.
Apakah ada tangkapan layar (thumbnail) yang diambil otomatis?

Ya! Sistem otomatis mengambil 1 screenshot representatif dari video dengan rasio vertikal 9:16 (270×480 px) dan menyimpannya langsung ke folder studio/aset/gaya/<slug>.jpg sehingga template kustom Anda memiliki thumbnail gambar yang rapi di menu pilihan gaya.

Apakah video mentah yang diunggah memakan ruang penyimpanan?

Tidak perlu khawatir. Terdapat saklar opsi Auto-Hapus video mentah setelah gaya diekstrak. Jika dicentang (default aktif), file video sumber yang berukuran besar akan otomatis dihapus setelah analisis selesai, hanya menyisakan kode template TSX dan file thumbnail kecil (~50 KB).

Apa perbedaan kategori "Animasi Bergerak" vs "Grafis Statis" saat ekstraksi?

Ekstrak Gaya memisahkan template ke dalam dua ruang kerja terpisah agar tidak saling bercampur:

  • Animasi Bergerak (Karakter & 3D Cel-Shaded): Dikhususkan untuk video animasi berbasis tokoh/karakter yang bergerak, berjalan, berbicara, atau bergaya anime/kartun 3D cel-shaded. Template disimpan ke motion/src/presets_animasi/ untuk Studio Animasi.
  • Grafis Statis (SVG & Motion Grafis): Dikhususkan untuk gaya presentasi berbasis teks, infografis, tipografi kinetik, dan ilustrasi flat 2D. Template disimpan ke motion/src/presets/ untuk Motion Standar.
Bagaimana cara menghapus template kustom yang sudah tidak dipakai?

Di tab Ekstrak Gaya Video pada kolom sebelah kanan (Pustaka Skill & Template Global), setiap kartu template kustom memiliki tombol merah bertuliskan ✕ Hapus. Mengklik tombol tersebut akan menghapus file preset TSX, thumbnail gambar, dan mencabut registrasinya secara instan tanpa merusak preset bawaan.

Panduan & FAQ: Pengaturan AI & Kuota Realtime Antigravity

Pelajari cara kerja integrasi model AI langganan Anda (Antigravity CLI, Claude Code, OpenAI Codex, OpenCode) serta pemantauan kuota token secara langsung.

Bagaimana Studio membaca sisa kuota Antigravity CLI secara realtime?

Studio membaca file sesi Language Server daemon Antigravity secara lokal di folder .gemini/antigravity/daemon/hub_*.json. Melalui komunikasi Connect-RPC internal yang aman, Studio memanggil RetrieveUserQuotaSummary secara berkala untuk menampilkan persentase token aktif tanpa perlu login ulang atau membuka browser.

Apa arti dari "Weekly Limit Remaining" dan "Five Hour Limit Remaining"?

Arsitektur kuota akun Google Antigravity memiliki dua lapisan proteksi batas pakai:

  • Weekly Limit Remaining (Batas Mingguan): Kuota kapasitas token besar untuk penggunaan intensif selama periode 7 hari. Akan terisi penuh kembali (reset) setiap siklus mingguan.
  • Five Hour Limit Remaining (Batas 5 Jam): Batas kecepatan (velocity rate-limit) untuk mencegah pemakaian beruntun tak terkendali dalam rentang waktu singkat. Jika habis, kuota ini pulih otomatis dalam waktu kurang dari 5 jam.
Mengapa Gemini Models dan Claude / GPT Models dipisahkan?

Google Antigravity menyediakan alokasi token terpisah untuk rumpun model Google (Gemini 2.5/3.8 Flash & Pro) dan rumpun model pihak ketiga (Claude 3.7 Sonnet, GPT-4o). Pemisahan ini memungkinkan Anda tetap bekerja dengan model Gemini saat kuota Claude sedang dalam masa tunggu reset, atau sebaliknya.

Apakah langganan chat pribadi (Claude Pro atau ChatGPT Plus) butuh saldo kartu kredit API?
